## 개선

- [x] **비유어는 괄호로** — `조종석(원격에서 양쪽을 조작하는 작업용 임시 VM)`. 줄표 삽입구는 문장 흐름을 끊는다.

- [x] **댓글봇: 도구 부재를 '할 말 없음'으로 보고하지 않는다** — preflight로 즉시 중단, 생성 실패는 exit 1.

## 버그수정

- [x] **`log`가 글 본문을 오염** — `review_post`의 stdout이 곧 본문인데 `log()`는 stdout에 쓴다.
      `[devlog-auto-retro] …`가 글 첫 줄로 발행될 뻔했다. `>&2` + 회귀 테스트.
- [x] **`sed | head -1` SIGPIPE** — `SUMMARY:` 줄이 둘이면 그날 글을 통째로 날린다(fail-open 위반).
- [x] **승급기 자리** — 계획은 `gh pr create` 앞이었는데 거긴 커밋·푸시 **뒤**라 규칙노트가 영영 안 실렸다.
- [x] **서명 필드 순서** — 계획의 `actor|at|body`가 실제로는 `post_id|actor|body|at`. 그대로 갔으면
      모든 서명이 불일치해 **에러 없이 조용히** 아무것도 주입되지 않았다(fail-closed라 티도 안 난다).
- [x] **댓글봇 소싱 가드** — `source`만 해도 전체 스캔이 돌아 작업 워크트리를 지웠다. 프리뷰 마친 댓글 한 배치를
      그렇게 날렸다. `devlog-auto-retro.sh`엔 처음부터 있던 가드가 이 파일만 빠져 있었다.
- [x] **codex CLI 재설치·인증** — 이관에서 사라져 댓글이 이틀 멈춰 있었다. `setup.sh`가 설치한 적이 없던 게
