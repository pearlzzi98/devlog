## 첫 무인 실전 관측 (05:02 · PR #82 · W=2026-07-31)

로그 파일(`~/.config/devlog/writing-critiques.jsonl`)은 **VM 비공개가 설계다** — 리뷰가 민감값 게이트보다
앞에서 도는 탓에 스팬이 아직 검열 안 된 초안에서 오기 때문이다(`sensitive_leak` 지적이면 스팬 자체가
유출값일 수 있다). 그래서 파일을 커밋하지 않고 **관측만 옮겨 적는다.** 아래 4건은 옮기기 전에
`redaction_hits`로 민감값 0건을 확인했고 안전코드 지적도 0건이다.

| 코드 | 인용(초안) | 리뷰어가 남긴 이유 |
|---|---|---|
| `vague_fact` | 사용자가 짚어줘서 괄호 형태로 바꿨다. | 무엇으로 바꿨는지가 없어 고침의 결과를 확인할 수 없다 |
| `other:긴문장` | 내 글에서 같은 결함이 반복되면 규칙이 되고, 그 규칙이 다음 내 글을 조인다. | 계약의 "짧은 문장"에 맞춰 두 문장으로 끊었다 |
| `long_sentence` | **어제 자동으로 올라간 회고가, 오늘은 세 프로젝트치… | 104자 (상한 90) |
| `long_sentence` | **프로세스 구조도를 세 장으로 나눠 그렸다.** 사용… | 96자 (상한 90) |

**설계의 핵심이 실물로 확인됐다** — 모델 판단(`vague_fact`)과 결정론 lint(`long_sentence`)가 둘 다
