**왜 보류인가**

1. **실패 신호가 0이다.** 자가진화 2단계는 *관찰된 실패* → 1사이클 개선이 규율인데, 코드 검증 게이트(길이·민감값·AI자기언급·과장) 거부가 0건, 사람이 되돌린 커밋도 0건이다. 두 지침 문서의 하드 제약이 위반된 사례가 없으므로 고쳐 쓸 문구를 지목할 근거가 없다.

2. **skip율 차이는 설계대로다.** Claude는 답글 담당이라 "새로 더할 가치 없음"이 정상 skip 사유(§4)인 반면, Codex의 최초 댓글은 본문이 짧거나 민감할 때만 skip한다(§5). 역할이 다르니 skip율이 갈리는 게 정상이고, 차이 자체도 5건 대 1건 — 30일간 4건 차이는 문구를 손볼 근거로 삼기엔 표본이 부족하다(Fisher 검정 기준으로도 유의하지 않음).

3. **남은 변경은 전부 추측이 된다.** "2~5문장 상한을 조정", "few-shot 추가" 같은 안은 그럴듯하지만 이번 집계가 가리키는 바가 아니다 — 규칙상 금지된 추측 변경이다.
