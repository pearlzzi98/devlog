# 글쓰기 규칙노트 (자동 승급)

반복 관측된 결함이 규칙으로 승급되어 여기 쌓인다. 기계가 추가하고, **줄을 지우면 거부**된다.
원문 지적은 여기 올라오지 않는다(VM 비공개). 상한 15줄.

- [fact_inconsistency] 본문 안의 숫자·사실이 서로 맞는지 확인한다. (근거 2회, 승급 2026-08-02, 최근 2026-08-03)
- [long_sentence] 한 문장을 90자 넘기지 않는다. (근거 3회, 승급 2026-08-02, 최근 2026-08-03)
- [orphan_metric] 수치를 쓰면 그게 무슨 뜻인지 한 마디 붙인다. (근거 2회, 승급 2026-08-02, 최근 2026-08-03)
- [raw_jargon] 영어·내부 기술어는 처음 쓸 때 괄호로 우리말 뜻을 붙인다. (근거 4회, 승급 2026-08-02, 최근 2026-08-03)
- [vague_fact] 뭉뚱그린 서술 대신 무엇을 어떻게 했는지 구체로 쓴다. (근거 3회, 승급 2026-08-02, 최근 2026-08-03)
- [misfiled_section] 막힌 것, 고친 것에는 실제로 막힌 일만 쓴다. (근거 2회, 승급 2026-08-03, 최근 2026-08-03)
